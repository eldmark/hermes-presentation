# Guía de exposición

## Teclas para quien presenta

- Avanzar: → o Espacio (o el botón del control de presentación). Retroceder: ←.
- `F`: pantalla completa. `B`: pantalla negra. `H`: mostrar el HUD con escena, paso y cronómetro.

## Checklist del día

- [ ] Probar la resolución del proyector y poner pantalla completa.
- [ ] Probar el control de presentación (qué teclas manda).
- [ ] Abrir `#/script` en los 3 celulares y desactivar el bloqueo de pantalla.
- [ ] Marcador en cero.
- [ ] Llevar el build local por si falla el internet (`bun run preview`).

## Reparto de líneas

Pendiente: asignar `presenter` (1, 2 o 3) a cada línea en `src/data/scenes.ts`. Propuesta inicial: A abre y cierra (1, 2, 3, 9), B cuenta los mitos (4, 5), C lleva el resto (6, 7, 8) y la actividad.

## Tiempos

La suma de las duraciones del guion es de 21 a 28 minutos. Es tentativo; cronometrar en un ensayo y recortar pasos en `scenes.ts`.
